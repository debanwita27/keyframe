## 1.7 Ambient perpetual motion under static holds
Frame-derived, never-settling motion (counter, drift, progress fill) that runs specifically *during* long holds so nothing reads as a freeze-frame. Every row below is PERPETUAL (loop=yes, no landing frame) — that is the definition of this family.

| move | status | params | description + recipe | source |
|---|---|---|---|---|
| `driftCamera` | built: DriftCamera | `amp=1.5%, period_f=180, axes=xy, loop=yes` | Slow sinusoidal pan/zoom of the whole comp. Recipe: `offset = amp*Math.sin(2π·frame/period)` via a shared `osc()` helper (easings.ts) on both axes; no `interpolate()` landing point, ever. | MOVE_VOCAB.md |
| `breathe` | built: Breathe | `scale=1→1.015→1, period_f=120, loop=yes` | Hero element idles via pure sine scale oscillation — cheapest "alive" signal for a locked-off shot. Recipe: `scale = 1 + 0.015*Math.sin(2π·frame/period)`. | MOVE_VOCAB.md |
| `orbitRing` | built: OrbitRing | `rotate=0→360, period_f=600, children_counter_rotate=true, loop=yes` | An ARRANGEMENT of icons on a circle rotates as a group forever; each child counter-rotates to stay upright. Recipe: parent `rotate=(frame/period)*360 % 360` linear; child `rotate=-parent.rotate`. See Conflicts vs. `globeSpin`/`orbitAlongPath`. | MOVE_VOCAB.md |
| `marquee` | built: Marquee | `x=0→-100%, period_f=300, ease=linear, loop=yes` | Infinite scrolling text/logo band. `linear` is a named MOVE_VOCAB exception here. Recipe: `x = -100 * ((frame/period) % 1)`. | MOVE_VOCAB.md |
| `filmGrain` (alias `grainShift`) | built: FilmGrain | `opacity=0.05, noise_seed=frame, loop=yes` | Animated per-frame noise kills the "flat vector" look through any hold. Recipe: `@remotion/noise` fractal noise re-seeded by `frame`, composited overlay/screen at low opacity — not a static grain PNG. | MOVE_VOCAB.md |
| `gradientDrift` | built: GradientDrift | `hue_rotate=±6deg, period_f=400, loop=yes` | Background gradient's hue slowly rotates so a full-bleed backdrop never sits dead. Recipe: `filter: hue-rotate(${6*Math.sin(2π·frame/period)}deg)` on the gradient layer only. | MOVE_VOCAB.md |
| `parallaxLayers` | built: ParallaxLayers | `depth=[0.2,0.5,1.0], amp=12px, loop=yes (tied to driftCamera)` | Layer offset scaled by depth band, tied to `driftCamera`'s oscillation for believable fg/bg separation. Recipe: `layer.translate = driftCamera.offset * depth`. | MOVE_VOCAB.md |
| `liveCounterTick` | built: LiveCounter | `rate=value/frame, digits=4, monospace_digits=true, jitter=optional sine, loop=yes (no landing)` | Perpetually-incrementing HUD/telemetry readout, zero keyframes, no settle point — pure `f(frame)`. Distinct from `counterUp` (eases to a final resting value; see Conflicts). Recipe: `value = base + frame*rate + jitterAmp*Math.sin(frame*k)`, tabular-nums. | A_micro-elements-animations |
| `bubbleDrift` (alias `chipFloat`, `iconCloudDrift`) | built: AsyncDrift | `amp_px=3-6, period_f=[90,130] per item, phase_seed=index, axis=y, loop=yes` | Ambient idle float for a settled sprite cluster: each item gets its own period+phase so the swarm never moves in lockstep. Recipe: `translateY = amp*Math.sin((frame-entryFrame)/period + phaseSeed)` per sprite, no shared clock. | A_recent-motion-4k-vertical, A_shipping-8-launch-videos, mthblt_B_the-team-put-in-so-much-work-and-effort-to |
| `concentricRingPulse` (alias `portalRingPulse`, `soundRingPulse`) | built: ConcentricRings | `ring_count=5, rotate_period_f=300, hue_cycle_period_f=300, ease=linear, loop=yes` | N concentric ring strokes on a shared radial gradient rotate slowly as a group around a bright core — reads as portal/eclipse/"sound source." Recipe: one `<g>` of concentric SVG `<circle>` strokes, `rotate=(frame/period)*360`; hue cycles via gradient-stop hue-rotate. Ambient/idle mode only — the reveal mode (`r` animating 0→N to unmask content) is family-1.5's `concentricRingMask`, not mine. | A_sparkle-vertical |
| `progressBarFill` | spec-only | `scaleX=[0.12,0.85], dur_f=whole-shot(~148f), ease=linear, transform_origin=left, loop=yes (no landing)` | A thin bar linearly fills across an entire static hold — the default "keep it alive" move when nothing else moves. Recipe: `scaleX=interpolate(frame,[0,shotEnd],[start,end])`, linear, never resets, never eases. | B_galactic-motion-art |
| `radialRevealGlow` | spec-only | `scale=[0.3,1.4], opacity=[0,0.9], driven_by=cardsRevealed/total (state, not raw frame), loop=yes` | Background radial-gradient halo whose scale/opacity track a state ratio instead of a timer, so it can't over/underrun an unpredictable hold length. Recipe: `progress=cardsRevealed/total; scale=lerp(0.3,1.4,progress)`. | A_not-your-average-ui-animation |
| `bgVideoZoom` | spec-only | `scale=[1.0,1.18], dur_f=whole shot, ease=linear, loop=yes` | Background media layer (video/image) scales up independently of a pixel-locked foreground — scoped to the bg layer only, unlike `driftCamera` (whole comp). Recipe: `bgLayer.scale=interpolate(frame,[0,shotEnd],[1.0,1.18])`, foreground untouched. | evanplace_A_8-the-trailers-a-one-stop-site-for-all-you |
| `globeSpin` | spec-only | `rotateY=0→360 continuous, tilt_deg=18 fixed, period_f=300, ease=linear, loop=yes` | A single 3D mesh spins about its own axis forever as an ambient establishing visual — self-rotation, not an arrangement of children orbiting a point. Needs CSS 3D (`perspective` parent + `rotateY`), no WebGL required for the flat-globe case. See Conflicts vs. `orbitRing`/`dragOrbit3D`. | Kirschberg__B_yummy-yummy-most-slop-please |

## 1.8 Synthetic UI interaction proof

| move | status | params | description + recipe | source |
|---|---|---|---|---|

Multi-waypoint/named-tag variant is the same mechanism with `per_target_stagger_f`. Recipe: `interpolate(frame,[start,click_at_f],[startXY,targetXY])`; at `click_at_f`, `scale:[1,0.85,1.1,1]` springSnap. | A_connect-to-figma-ui-anim, jittervideo_A_introducing-superagents-remix-resize-trans |

## 1.9 Radial/polar concrete-object placement
N related objects (icons, questions, chat bubbles, text copies) placed at fixed polar coordinates around a shared center rather than in a list — the spatial arrangement itself carries the meaning ("surrounding," "orbiting," "radiating from"). All rows one-shot unless noted.

| move | status | params | description + recipe | source |
|---|---|---|---|---|
| `radialChatCluster` | built: RadialCluster | `radius_px=const, angles_deg=fixed array (e.g. [200,260,320]), stagger_f=3 (by angle order), dur_f=14, ease=springSoft, loop=settle then perpetual per-item idle` | N children at fixed polar coordinates around a shared center, entrance-staggered by angle order, then idling in place once settled. Recipe: `x=cx+r*cos(θ), y=cy+r*sin(θ)` computed once per element from a fixed angle array; stagger entrance by angle order. | A_shipping-8-launch-videos, Kirschberg__B_yummy-yummy-most-slop-please |
| `networkBloom` | spec-only | `node_count=9, stagger_f=1, ease=springSnap, radius=jittered per node, loop=no` | A cluster of N nodes scatters from a fixed center at seeded-random polar positions (`radius=rMin+rand()*(rMax-rMin), angle=i*(360/N)+jitter`), fading/scaling in with a short per-node stagger — "a network forming around a hub." Radius is randomised (vs. `radialChatCluster`'s clean fixed ring). | A_launch-video-wip-vertical |
| `radialNodeBurst` | spec-only | `node_count=24, dur_f=140 (out) / shorter (retract), stagger_f=3, ease=expoOut (expand)/expoIn (retract), loop=no (reversible)` | A center icon erupts into N nodes at polar coordinates connected by spoke-lines whose `strokeDashoffset` draws in lockstep with node travel; the identical move run backward retracts nodes through the icon into a point. Adds drawn connectors vs. `networkBloom`. Recipe: one shared `progress` drives both node radius and line dash-offset; reverse easing for retract. | Kirschberg__B_yummy-yummy-most-slop-please |
| `scatterArc` | spec-only | `stagger_f=2, dur_f=24, ease=expoOut, path=cluster→arc, loop=no` | Elements in a dense cluster fly apart along individual paths to precomputed positions along a wide arc — a constrained-angle-range variant of radial placement (a slice of the circle, not the full round). Recipe: precompute target `{x,y}` per element along an arc-sampled curve; `expoOut` per-element with `stagger_f`. | Kirschberg__B_yummy-yummy-most-slop-please |
| `radialTextBurst` | spec-only | `rings=6, rotate_deg=35, dur_f=4 (pulse), opacity=0.6, loop=no (may repeat)` | A string tiled as multiple `<text>` copies at polar coordinates in N concentric rings around a target centroid, briefly opacity-pulsed and rotated a few degrees — a full-bleed graphic "hit" built entirely from typography rather than particles. Recipe: place copies at `r=ringIndex*spacing, θ=i*(360/perRing)`; pulse all rings' opacity together. | B_galactic-motion-art |
| `shapeClusterFormation` | spec-only | `path=circle\|spiral\|heart, per_tile_stagger_f=2, dur_f=60, ease=springSoft, loop=no` | N already-on-screen elements FLIP-animate from their current layout position to a point sampled along a named parametric curve, so the emergent arrangement itself becomes the recognisable shape — a re-layout move, not a mask. Recipe: sample N points along the curve's parametric function; each element springs from its current `{x,y}` to its sampled target. | Kirschberg__A_new-site-designed-in-figma-built-in-cursor |
| `orbitAlongPath` | spec-only | `path=circle, radius_pct_of_frame=32, arc_deg=[200,260], dur_f=14, ease=expoInOut, loop=no` | A single element's position is parametrised in polar coordinates along a path (circle here, generalises to any SVG path via `getPointAtLength`) and traverses a bounded arc once, rotation locked tangent to travel direction — the one-shot, single-element counterpart to `orbitRing`'s perpetual multi-child rotation. Recipe: `θ=interpolate(frame,[0,dur],[200,260]); x=cx+r*cos(θ), y=cy+r*sin(θ)`; `rotate` set to path-tangent angle. | mthblt_B_jitter-2024-powered-by-jittervideo-magic |

### Conflicts kept apart (families 1.7-1.9)
| move A | move B | how to tell them apart |
|---|---|---|
| `OrbitRing` | `RadialCluster` | `OrbitRing` rotates continuously as ambient background; `RadialCluster` places items statically with per-item idle and staggers arrival — same geometry, different intent. |
| `motionTrail` | `holoEchoOutline` | `motionTrail` offsets echoes in TIME (2f apart, treatment layer); `holoEchoOutline` offsets in SCALE and HUE (mask-as-subject family). |
| `globeSpin` | `orbitRing` | `globeSpin` is ONE mesh perpetually self-rotating about its own axis; `orbitRing` rotates an arrangement of children around a circle while each counter-rotates to stay upright. |
| `globeSpin` / `orbitRing` | `dragOrbit3D` | The first two are perpetual, machine-driven, perfectly linear; `dragOrbit3D` is a bounded one-shot with frame-seeded jitter simulating an imperfect human drag — never make it perfectly linear or it stops reading as a drag. |
| `cursorTravelClick` | `cursorDrag` | `cursorTravelClick` is a single travel-then-click event; `cursorDrag` sustains a drag with a bound value/panel state interpolating in lockstep with cursor position for the whole gesture. |
| `stateSwap` | `HardSwap` | `stateSwap` is a one-time eased UI flip caused by a specific click event; `HardSwap` is family 1.4's periodic, un-eased material/treatment re-skin on a fixed interval with no causal trigger. |
| `radialChatCluster` | `networkBloom` | `radialChatCluster` uses a fixed radius + fixed angle array (clean ring); `networkBloom` randomises radius per node from a range (organic scatter). |
| `radialNodeBurst` | `networkBloom` | `radialNodeBurst` adds drawn spoke-lines from center to each node and is reversible (expand/retract); `networkBloom` has no connectors and only ever expands. |
| `liveCounterTick` | `counterUp` (MOVE_VOCAB) | `liveCounterTick` never eases or lands — pure `f(frame)` for the life of a hold; `counterUp` eases into a fixed final value once, as an entrance. |
| `progressBarFill` | `liveCounterTick` | Both are pure-frame ambient-during-hold moves; `progressBarFill` drives a bar's `scaleX`, `liveCounterTick` drives a numeric readout — pick per asset type, don't collapse into one move. |

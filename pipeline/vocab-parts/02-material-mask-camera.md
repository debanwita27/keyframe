## 1.6 Camera-through-space / continuous never-cutting take
The whole piece (or the overwhelming majority) is one unbroken camera/composition take; apparent scene changes are flashes, morphs, or re-skins layered on top, never a hard cut. Corpus's dominant structural pattern — 11 of 25 byshubh_ refs have ≤1 hard cut — and undersupplied in the built library relative to that weight.

### Conflicts kept apart (families 1.4-1.6)
| move A | move B | how to tell them apart |
|---|---|---|
| `treatmentStutterSwap` | `treatmentCrossfadeSwap` | A: zero crossfade, quantized hard cut (glitch energy). B: eased opacity crossfade over `dur_f` (material-transformation feel). Same goal (swap N variants on one asset), never interchange the easing. |
| `treatmentStutterSwap` | `glitchMaterialMorph` | A: REGULAR quantized grid (`step_f=4`, periodic). B: IRREGULAR seeded-random interval array (4-7f, chaotic, never periodic). Periodic reads mechanical; irregular reads alive/unstable. |
| `irisMaskReveal` | `irisSweepCollapse` | A expands a circle to REVEAL content underneath (reveal device). B is a closing wedge/shutter that OCCLUDES as a transition between two unrelated motifs (not a reveal). Opposite direction and purpose. |
| `travelingShapeWipe` | `vanishThroughGap` | A moves the SHAPE across a static object/content (two-shape sandwich, content re-hidden after). B keeps the shape STATIC and moves the OBJECT through it via z-order clip (one-way occlusion, particle burst on disappearance). |
| `travelingShapeWipe` | `numeralWipeTransition` | A re-hides content after the shape passes (momentary peek). B's glyph mask permanently swaps to the new layer once it passes (one-way reveal, outgoing layer dropped). |
| `concentricRings` | `concentricShapeBurst` | A = thin ring STROKES sharing one radial gradient, rotating/expanding (portal look). B = full SOLID silhouette copies scaled to different targets, colours cycling by layer index (burst look). Different render primitive. |
| `dollyToUI` (existing) | `dollyThrough` | dollyToUI = 2D zoom+translate to a flat UI focus point inside a static scene. dollyThrough = true z-axis 3D camera translation traversing a 3D world/sections, FOV widens. |
| `dollyToUI` (existing) | `heroPushMacro` | dollyToUI: moderate scale, `expoInOut`, UI-detail inspect. heroPushMacro: extreme 8-12x push, `expoIn`, closing hero/loop beat ending on raw texture, not a UI detail. |
| `whipZoomOut` | `PullOut`/`WhipPan` (existing) | PullOut is a subtle whole-shot ambient pull (1.08→1). WhipPan is a lateral (x-axis) sweep. whipZoomOut is an extreme fast (6f) SCALE pull-back (1→0.35) used as a transition punch — different axis and magnitude from both. |
| `chromeTumble3D` | `Orbit3D` (existing) / `dragOrbit3D` | Orbit3D(existing) = short entrance settle (single axis, ~40f). chromeTumble3D = continuous multi-axis ambient loop with a freeze window (43f+). dragOrbit3D = single-axis rotation driven by a frame-seeded IRREGULAR curve simulating human drag, not a smooth loop. |
| `fillToStroke` | `anchorRingOrbit` | A changes the RENDERING of one fixed shape in place (fill↔stroke, same geometry). B adds NEW decorative points orbiting around a mark whose own rendering never changes. |

|---|---|
